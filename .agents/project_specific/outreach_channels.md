# Project Rule: Medium-Specific Referral Outreach Formatting

> **Scope:** Project-Specific (Job Applier Repository)

Format referral request cards specifically for the target medium:

1. **LinkedIn DMs / InMail:**
   - Use clean Plaintext + Unicode bullet points (`•`).
   - DO NOT use Markdown bold (`**`) or headers (`##`), as they break in LinkedIn chat UI.

2. **Email / Gmail Outreach:**
   - Use Rich HTML with clean inline typography, styled bullet points, and hyperlinked text.

3. **GitHub / Dev Portals:**
   - Use standard GitHub-Flavored Markdown (`.md`).

4. **WhatsApp / Mobile DMs:**
   - Use scannable WhatsApp bold text (`*bold*`) and concise bullet points.
