# Project Rule: Angular Job Targets & Scoring

> **Scope:** Project-Specific (Job Applier Repository)

## Targeting & Classification
- **Target Position:** Senior Angular Frontend Developer / Lead UI Engineer
- **Tech Stack:** Angular (14-18), RxJS, NgRx, Signals, TypeScript, Core Web Vitals, Micro-frontends, Jasmine/Karma/Cypress
- **Company Profile:** Product-based Companies (Full-Time Employee). Filter out WITCH/generic service agencies.
- **Location Preference:** Hybrid or Work From Office (WFO). Global Remote is last priority.

## Quantifiable Skill & Experience Gap Analysis
Calculate and display explicit skill/experience deltas for each listing:
- **Skill Experience Delta:** Compare user's CV experience vs JD requirement (e.g. `Angular: 4.0 yrs vs 5.0 yrs req (Gap: -1.0 yr)`).
- **Missing Skills Delta:** Identify unmentioned skills and minimum required experience (e.g. `Cross-Team Communication: 0 vs 0.5 yr min (Gap: Missing)`).
- **Color-Coded Visual Health Indicator:**
  - 🟢 **Green:** Meets or exceeds requirement (Delta >= 0).
  - 🟡 **Yellow:** Minor gap (e.g. 3.0 yrs vs 4.0 yrs required).
  - 🔴 **Red:** Missing critical skill or major gap (Delta >= -2.0 yrs or Missing).
